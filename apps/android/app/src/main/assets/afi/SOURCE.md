# AFI industrial subdivision reference

Public zone locations, indicative lot geometry, advertised facts and official document links
from the [AFI interactive map](https://afi.e-industrie.gov.tn/) and the [AFI document archive](https://www.afi.nat.tn/fr/documents/).

`302312c5f2add5a44e3031fb9d1735d4e1ebb19951b47698a17330df42293e12`.
The Android export preserves each source date. It includes no private Atlas references or PDFs.

Regenerate with `python3 scripts/export_afi_android.py <atlas-data>/map-afi apps/android/app/src/main/assets/afi`.
