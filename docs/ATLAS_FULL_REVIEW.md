# Full archive second pass (operator-side)
Use after the existing first pass finishes; use a separate pinned checkout. No source updates. The command scans approved roots once, writes an immutable priority plan and then processes every available document in 20-page windows. Each committed window is reused on restart with the same output, roots, raster strategy and page cap. No need to rerun manually per batch. Single writer lock. In adaptive mode OCR every page of high-priority cadastral/OTC/plan/locality/failed/recovered/vector documents; other docs OCR only when native text is absent. This is a recall/cost heuristic, not proof of accuracy. Use all mode in a different run if all raster pages are required. Default cap 500 pages per document: larger documents are retained with explicit page-cap state; raise on a new run if needed (max 10000). Use --max-windows for controlled partial runs (0 = all).
    
    python -m scripts.atlas_archive_full_review --first-pass-run PRIVATE_FIRST_RUN --archive-root APPROVED_ROOT --output-directory PRIVATE_NEW_OUTPUT --raster-mode adaptive

Output parent must exist and be 0700. Only explicit non-overlapping archive roots; do not scan the entire home directory. For bigger roots set reviewed --max-scan-files / --max-scan-bytes / --max-probe-files. If initial inventory fails before plan creation, keep that failed output and use a new output; if the plan exists, the same output resumes. On unexpected crash a private temporary work directory may remain; no automatic deletion. A terminal failed document is retained, not repeatedly retried in the same run. A complete available queue means attempted, not successfully OCRed or complete national coverage.
    
Each invocation writes a new private combined index and aggregate comparison, preserving first-pass evidence, method/page and qualified suffixes. Deep suffix-qualified references are kept for review and not stripped into bare numeric graph links. Graph rebuilt from explicitly reviewed scopes/sources (defaults to the first run inputs; override --scopes and --sources if reviewed files exist). Native/raster observations are independent; no cross-pass/page joins. The graph remains candidate-only. Current exact numeric title lookup is unchanged; suffix-qualified evidence is retained in private index for manual review. Report actual title/parcel evidence gains, recovery, capped/failed/pending states; no official status or ground geometry inferred. Actual local testing, source-field mapping, georeference, rights/review and Amlak integration remain separate gates. No raw outputs should be uploaded.
