# Private source registry adapter

This is a companion to ATLAS MASTER #20 and the existing property index, not a new master plan. It does not run on or change the active Mac archive checkout.

1. Inspect an existing stable standalone SQLite copy: python -m scripts.atlas_source_registry inspect --db PRIVATE_COPY --snapshot-sha256 EXPECTED_SHA --snapshot-kind mainfile_diagnostic --output PRIVATE_SCHEMA_JSON
2. Review actual table names, columns and sampled JSON key hints locally. Values are not printed. Create a 0600 PRIVATE_REVIEWED_SOURCE_MAPPING JSON with snapshot_kind, snapshot_sha256_private and mappings. Each mapping has table, fields, reviewed_registry_scope_values. A field rule is {"column":"name"}, {"column":"attributes_json","json_path":["attributes","field"]}, or a constant {"literal":"source-version"} for source namespace/service/layer/version only. Scope translations must be reviewed against authoritative registry scope, not presumed from administrative region. No raw source URLs or values in GitHub.
3. Export registry and a compatible sources list: python -m scripts.atlas_source_registry export --db PRIVATE_COPY --mapping PRIVATE_MAPPING --output PRIVATE_REGISTRY --candidate-sources-output PRIVATE_SOURCES
4. Supply PRIVATE_SOURCES plus separately reviewed document SHA-to-registry-scope annotations to atlas_property_index build. This stages candidate edges only. Keep registry with all unresolved rows; the candidate list is a projection, not the full inventory.

Original snapshot remains immutable. Each selected table is fully counted; incomplete keys, duplicate source identities, unreviewed scopes, missing/non-text references are retained as unresolved. Numeric source references cannot prove original leading zeros and are not automatically joined. Scan ordinal is a diagnostic pointer, not a persistent ID. Snapshot digest binds the mapping; no automatic source-field discovery or official legal verification. Actual local schemas and mappings still require operator inspection. Never expose private fields or schema to public clients. Only selected tables are represented in export; inspect lists all discovered tables. Snapshot kind is operator-declared; use mainfile_diagnostic for the current copy.
