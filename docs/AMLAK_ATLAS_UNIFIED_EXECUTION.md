This is the single cross-workstream execution checklist, not a replacement master or an authorization to deploy.

## 1. Mission and approved priorities
One Tunisia real-estate platform: official cadastral plan archive and title/parcel evidence graph (Atlas), private owner document interpretation and geometry workbench (Amlak), buyer map/search and authorized CRM listings. Begin in Nabeul / Kélibia, expand by actual verified coverage. Sales only. Preserve crimson/pearl, Arabic default RTL and French. No fabricated geometry, ownership or availability.
The primary Atlas deliverable is official Plan de cadastre with issuer, title/parcel/office references, original document hash and traceable source; PAU/AFI/INS, market data and administrative boundaries are supporting, not substitutes.

## 2. Shared data model and workflow
- Immutable raw files and source-scoped identifiers -> derived observations -> candidate relations -> reviewed relations -> consent/license-approved public projection. Retain all unknown/unlinked rows and rejected alternatives, duplicate source links and historical versions; dedup blobs by SHA256 without destructive entity merges.
- Distinguish registry office + TF (including suffix), parent title, cadastral parcel number, lot/subdivision/phase, CRM commercial code, location text and historical aliases, administrative INS identifiers, source document and page. Never join by similar number or name alone.
- Whole registered estate area; total abstract rights parts; each owner/right category/row with exact decimal parts; owner's matched numerator; arithmetic share percentage and optional pro-rata area (review only); physically delimited plot area; offered sale area; measured map area. Never default to 100% based on an individual certificate heading. Rights categories and complete page coverage must be accounted for before aggregate balance is interpreted. Never draw a fraction of a polygon as the owner's exclusive land.
- Preserve raw strings, page/line/word geometry, numeric units and OCR view, confidence, alternatives, user correction, reviewer decision and revision. OCR can propose, not certify current legal ownership. Conflict != absent != unreadable. Do not hardcode real reference values as recognition hints or tests.
- Private document analysis -> administrative/place candidates (INS 2024, original historical locality retained) -> exact scoped Atlas lookup -> candidate plan/geometry -> reviewer resolves and grants publication. Owner point or same locality alone does not prove a parcel match. No official geometry without independent grounding.
- Public payloads allowlisted; retain required attribution or exclude restricted sources. Sensitive CIN/DOB, unrelated owners, raw PDF/archive URLs, exact private location and private join keys never leak. Authorized redacted plans/documents only; revocation removes public derivatives.
