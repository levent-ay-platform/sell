# Candidate handoff to existing Amlak contract
This is a private offline staging draft, not an authorized database import. Use after the actual Atlas property index has reviewed document scope, and a private document/outline case and its independently sourced control QA exist. It reuses ReviewedAtlasParcel DTO, not the approved-plan bridge. Candidate namespace identifies internal archive evidence, not an issuing authority. Neither CANDIDATE nor PLAN_NOT_GEOREFERENCED may be used as an official boundary.

Selection JSON (0600) kind PRIVATE_ATLAS_CANDIDATE_SELECTION: index_sha256, document_sha256, case_sha256, controls_sha256, qa_sha256 (file byte hashes), page, outline_ordinal, registry_scope (same as reviewed index), locality_key (explicit reviewer selection), title and parcel objects {"number":"00123","suffix":null}. The number and optional suffix must occur together in the same observation on the selected page. Suffixes retain a separate normalized comparison representation; DTO uses number/suffix. No scope inferred from map position. Multiple labels on one page still do not establish legal parcel identity.

Manifest JSON (0600) kind PRIVATE_ATLAS_CANDIDATE_HANDOFF_MANIFEST, index_sha256 and items list containing selection_path, case_path, controls_path, qa_path. All paths are local private files.

    python -m scripts.atlas_amlak_candidate_handoff --index PRIVATE_INDEX --manifest PRIVATE_MANIFEST --output-directory NEW_PRIVATE_DIR

Recomputes QA from the bound case/controls and rejects altered results. Successful geometric candidate is CANDIDATE; failed QA stays PLAN_NOT_GEOREFERENCED with null geometry. All redistribution flags false. Duplicate outline selections quarantined. Every requested item accounted for, including failures. Actual document/source/control authenticity is not certified. Output candidate-import-draft.json is not authorized for import; handoff-report.json preserves private evidence. Keep these outside served directories and APKs. A separately authorized operator must validate schema, source rights, access controls and real data before importing. Existing approved private bridge and public export gate unchanged. No server or Android deployment.
