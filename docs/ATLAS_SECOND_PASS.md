# Second-pass pilot — private Atlas
After the complete current first-pass chain only, use a separate checkout and new private output directory. This orchestrator reads the accepted manifests, preserves prior evidence, and scans explicitly approved nonoverlapping roots once with extensionless PDF detection. It produces a lossless all-catalogue-hash priority plan and an optional small deep-review pilot; multiple matching copies are retained but not counted as distinct hashes. No new eligible queue is substituted into the old chain.

    python -m scripts.atlas_archive_next_pass --first-pass-run PRIVATE_FIRST_RUN --archive-root APPROVED_ROOT --output-directory NEW_PRIVATE_RUN --max-documents 10 --pages-per-document 5 --raster

Repeat --archive-root only for other specifically approved archives. Set --max-documents 0 to inventory and plan without OCR. At most 20 docs and 100 page attempts per invocation. Pilot prioritization is heuristic; missing evidence remains unknown. The pilot writes separate page windows, not a new final property index. Compare with prior evidence and review source, identifiers, suffixes, authority, and geographic controls before accepting any actual link. Only aggregate terminal counts may be shared. This module cannot resume pilot windows yet; completed windows remain on disk for the next implementation stage. Do not run while first pass is incomplete or change its checkout. Real execution on owner data remains required.
