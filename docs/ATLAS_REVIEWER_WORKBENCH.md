# Atlas reviewer workbench (private local staging)
A read-only Arabic RTL HTML workbench generated on the Mac from the existing private property index. Not an authenticated HTTP route and not a production Atlas/Amlak deployment. Never copy the output to a served directory, public artifact, GitHub or APK. The report includes private title references and SHA digests. Keep the containing directory 0700 and files 0600.

    python -m scripts.atlas_reviewer_workbench --index PRIVATE_INDEX --output-directory NEW_PRIVATE_DIR

Optional --spatial-context PRIVATE_FEDERATED_CONTEXT requires an exact graph fingerprint binding. Optional --first-pass-run PRIVATE_FIRST_RUN --document-sha PRIVATE_SHA includes up to 24 SHA-bound original direct vector page outline previews for one selected document. It does not pretend that PDF coordinates are geographic coordinates. Full original evidence stays in private files. No raw PDF rendering, owner names, raw OCR or source URLs in the HTML. Exact number/qualified reference search, review status filter, page-local evidence, context, and review checklist. No approval button or automated promotion: existing independently reviewed Atlas export/AMLak import gate remains the only publication staging path. The current owner parcel editor remains unchanged. Browser file-based UI is not access control; do not share or serve it. No network calls; CSP denies connections. Real data and visual device acceptance remain required.

V7: the workbench now presents upstream sector and district context alongside governorate and delegation identifiers, with a dedicated administrative-parent-conflict filter. Each document association requires an exact source-scoped candidate edge, in addition to the graph fingerprint. Conflicts are retained for review, not reassigned, and no registry scope or legal boundary is inferred. No additional private data is exported; the local read-only restrictions remain.
