# Case-bound Atlas candidate search in Amlak
Existing verification gateway, no new public route. POST /api/v1/reviewer/cases/{caseId}/atlas-candidates with geometryId, registryScope, localityKey. Verified assigned reviewer, active unexpired case, latest property revision, current evidence consent, persisted DOCUMENT_ONLY title and parcel references required. Exact scope/locality and source record match. Returns only bounded counts (51 means capped, not an exact total), official-source count, geometry-presence count, ownershipVerified false, mayPublish false. No candidate polygon, source ID, hash or title leaves the server. It does not import staged Atlas data or confer ownership. Existing owner and public endpoints remain unchanged. The live PostGIS integration fixture exercises candidate matching and consent withdrawal; dedicated branch workflow exercises synthetic HTTP/SQL contract. Real import, role/rights and device UI acceptance remain outstanding.
