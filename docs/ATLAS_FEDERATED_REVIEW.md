# Federated private review
Single local operation after source schema review. Provide the combined first/deep property index, explicit reviewed document scope annotations, and a 0600 source manifest {"kind":"PRIVATE_ATLAS_FEDERATED_INPUTS","sources":[{"snapshot_path":"PRIVATE_STANDALONE_COPY.sqlite","mapping_path":"PRIVATE_REVIEWED_MAPPING.json"}]}. Each snapshot is checked against its own mapping SHA and must be a standalone copy. No live DB, raw archive upload, source access bypass, or public endpoint.

    python -m scripts.atlas_federated_review --index PRIVATE_COMBINED_INDEX --sources-manifest PRIVATE_MANIFEST --scopes PRIVATE_SCOPES --output-directory NEW_PRIVATE_OUTPUT [--query PRIVATE_QUERY]

Produces a private federated registry (all selected rows including duplicates), property index with rebuilt candidate graph, spatial context, summary, and optional dossier. Cross-snapshot identical scoped keys are withheld even if one source is incomplete. No automatic merge or cross-snapshot identity guess. Registry scope is explicitly reviewed and never derived from an administrative intersection. Spatial context bound to graph fingerprint; source mapping and snapshot digests retained. Source-specific rows and 24-governorate/279-delegation contextual counts are not cadastral coverage or official plans. Unmapped tables remain in the original copies; mapping coverage requires operator verification. No actual source schema mapping or public app integration yet. Keep all outputs local and private.
